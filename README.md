# Programacion I

Programas de Programación I.

## Archivos

- `arreglos_1909.py`: actividad del 19/09. Dice si cada alumno está regular.
- `torneo_actividad01.py`: inscripción y parejas, solo en memoria.
- `torneo_actividad02.py`: la misma inscripción guardada en archivos.
- `buffet.py`: práctica del buffet.
- `informe_buffet.md`: informe de esa práctica.

## Cómo ejecutarlos

Desde esta carpeta:

```bash
python3 arreglos_1909.py
python3 torneo_actividad01.py
python3 torneo_actividad02.py
python3 buffet.py
```

En la actividad del 19/09 un alumno está regular si el promedio de las 4 notas es mayor o igual a 6 y la asistencia es mayor o igual a 75%.
